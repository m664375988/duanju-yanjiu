即梦 AI 提示词怎么写：从「让人物走过来」到电影感万能公式

2026-08-09 · AI 工具 · 短剧研究所

即梦这类工具不是「理解你的灵感」，而是「执行你给的画面条件」。条件越完整，结果越接近预期；条件越模糊，AI 越自由发挥——这也是新手总觉得「画面跑偏、人物变形」的根因。

一、万能公式：7 个要素

主体 + 场景 + 动作状态 + 镜头运动 + 画面风格 + 光影氛围 + 画质要求

  • 主体：别只写「一个女孩」，写「一位年轻女生，穿浅色风衣，神情自然」。
  • 场景：别只写「城市」，写「夜晚城市街道，霓虹灯牌，雨后路面反光」。
  • 动作状态：明确主体在做什么，如「缓慢回头」「轻轻抬起头」。
  • 镜头运动：缓慢推近 / 拉远 / 横移 / 环绕 / 低角度仰拍。
  • 风格：电影感 / 赛博朋克 / 国风 / 商业广告质感（别堆多个冲突风格）。
  • 光影：暖色路灯 + 冷色霓虹、清晨柔光、逆光轮廓。
  • 画质：画面清晰、细节丰富、人物五官自然稳定。

二、动作要写「动作链」，别堆动作

新手爱写「女孩奔跑、回头、挥手、跳跃、拥抱」——对 AI 是多个动作同时发生，容易肢体粘连。用「先 / 随后 / 接着」连接，一个镜头安排 3–5 个连续动作足矣：

女孩沿街道向前奔跑，听见身后呼喊后放慢脚步，
停下转身看向后面露惊喜，随后抬起右手挥手。

三、新手先掌握 3 种运镜

  • 缓慢推近：强调表情、物品细节。「镜头从中景缓慢推近至人物面部特写」。
  • 平稳跟随：人物走路、进门。「镜头从侧后方平稳跟随，人物居中」。
  • 缓慢环绕：展示造型、产品。「镜头围绕主体顺时针缓慢旋转半周」。
一条几秒的视频只写一个主要运镜，同时要求俯冲+旋转+拉远反而画面失控；图生视频务必写 prompt（不写效果靠运气）；长动作一定写「时长 6 秒 / 9 秒」，否则默认可能只有 3 秒。

四、可直接抄的人物模板

一位(人物身份)，穿(服装风格)，站在(场景环境)，
(动作状态)，镜头(镜头运动)，(光影色调)，(画面风格)，
背景(背景处理)，画面清晰，人物五官自然稳定，细节丰富。
