短剧创作者必看：红果、番茄、抖音平台分成哪家强？

2026-08-30 · 变现渠道 · 短剧研究所

一、引言

作为短剧创作者，选择一个分成高的平台至关重要。本文将对比红果、番茄、抖音三大平台，帮助你找到最适合的短剧发布平台。

二、红果平台

  • 分成比例：红果平台的分成比例较高，通常在50%-60%之间。
  • 操作步骤：注册账号 → 制作短剧 → 上传作品 → 申请分成。
  • 坑点：审核时间较长，需要耐心等待。

三、番茄平台

  • 分成比例：番茄平台的分成比例在40%-50%之间，相对较低。
  • 操作步骤：注册账号 → 制作短剧 → 上传作品 → 申请分成。
  • 坑点：作品流量扶持有限，需要自行推广。

四、抖音平台

  • 分成比例：抖音平台的分成比例在30%-40%之间，相对较低。
  • 操作步骤：注册账号 → 制作短剧 → 上传作品 → 申请分成。
  • 坑点：内容审核严格，需要遵守相关规定。

提示：选择平台时，除了考虑分成比例，还应考虑平台的流量、用户基础和作品类型。
